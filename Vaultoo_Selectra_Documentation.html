Overview

What this system is and why it exists
🏆

Vaultoo is the core product. Selectra is a demo application bundled alongside it solely to showcase Vaultoo's integration capabilities in a real-world, end-to-end scenario. It is not a separate product — it is a proof-of-concept integration target.

Vaultoo solves a common enterprise problem: how do you grant someone temporary access to an account or platform without ever sharing the actual password? Traditional approaches — sharing credentials via email, chat, or password managers — carry significant security risks. Vaultoo eliminates that risk entirely.

The platform works through a controlled access loop: an Owner stores encrypted credentials in Vaultoo's vault. A Requester asks for time-limited access. The Owner approves and a one-time password (OTP) is generated. The Requester verifies the OTP in the target application (Selectra in this demo) to begin a monitored session. Throughout the session, the Owner retains full visibility and can terminate access instantly.

Selectra is a pre-built AI interview web application that ships as a demonstration integration. It implements Vaultoo's public API pattern — OTP verification, session status polling, activity logging, and live screen capture. Any third-party application can replicate this same pattern to integrate with Vaultoo.

Vaultoo — Features

Core platform capabilities
🔐 Account Vault

Store platform credentials encrypted with AES-256-CBC. Passwords are never exposed to requesters — only the owner ever holds the key.

📨 Access Requests

Requesters submit time-limited access requests with a stated duration and reason. Owners approve or deny with a single click.

🔑 OTP Sessions

Approved requests auto-generate a cryptographic one-time password. The requester must verify it inside the target app to begin a session.

📺 Live Screen Feed

Real-time screenshots streamed from Selectra to the owner dashboard every 3 seconds. No plugins required — pure browser-based capture.

☠️ Session Kill Switch

Instantly terminate any active session. The requester is automatically force-logged-out of Selectra in real time.

⏱ Session Extensions

Requesters can ask for additional time mid-session. Extension requests appear in the owner dashboard for approval or denial.

📊 Activity Logging

Every action performed during a session is logged with timestamps, URLs, details, and automated risk flags for later review.

🛡 Sentinel Risk Engine

Automated per-session risk assessment producing LOW / MEDIUM / HIGH / CRITICAL ratings based on behavioural signals.

Selectra — Demo Integration App

Reference implementation showing how any app plugs into Vaultoo
⚠️

Selectra is not a Vaultoo product. It is a standalone AI interview web application used purely as a demonstration target. It ships alongside Vaultoo to make the platform's capabilities tangible and testable. Any third-party application can replicate the same integration by consuming Vaultoo's public /api/v1/* endpoints.

What Selectra demonstrates

🔐 Vaultoo OTP Login

Replaces standard login with a Vaultoo-issued OTP flow. The user never sees a password — the session is entirely Vaultoo-governed.

📡 Live Screen Capture

Uses html2canvas to screenshot the DOM every 3 seconds and POST compressed JPEG frames to Vaultoo's screen-share endpoint.

⏲ Session Timer

Draws a live countdown from expiresAt returned by Vaultoo. Polls session status periodically and force-logs out on expiry or kill.

🙋 Extension Requests

Provides a modal for the requester to ask for more session time. Sends a request to Vaultoo and shows pending/approved/denied status.

Selectra's own app functionality (demo content)

Beyond the Vaultoo integration, Selectra is a fully functional AI interview platform that showcases the kind of real-world application Vaultoo is designed to protect. It includes a multi-role interview simulator (Frontend, Backend, Full Stack, Data Science, DevOps, Cybersecurity), four-dimension real-time scoring (Clarity, Accuracy, Completeness, Confidence), explainable AI analysis, and a comprehensive report generator. These features exist as realistic demo content — they make the platform feel like a genuine production app rather than a placeholder.

Security Architecture

Defence-in-depth measures baked into the platform
🔐
AES-256-CBC Encryption
All stored credentials are encrypted with AES-256-CBC before being written to the database. The encryption key never leaves the server environment. Even a full database dump reveals no usable credentials.
🪪
httpOnly JWT Cookies
Authentication tokens are stored exclusively in httpOnly, Secure, SameSite=Lax cookies — inaccessible to client-side JavaScript. This prevents XSS-based token theft entirely.
🎟
One-Time Passwords
OTPs are cryptographically generated, time-limited, and single-use. Once a session is started or the OTP expires, it is permanently invalidated and cannot be reused.
⚡
Instant Kill Switch
Owners can terminate any active session with one click. The session is marked KILLED server-side and Selectra detects this on its next poll, forcing an immediate logout.
🕵️
Sentinel Risk Engine
Continuous risk scoring analyses session behaviour and assigns LOW / MEDIUM / HIGH / CRITICAL ratings. Risk flags are attached to every activity log entry.
🔑
bcryptjs Password Hashing
All user passwords are hashed with bcryptjs at 12 salt rounds before storage. Plain-text passwords are never persisted or logged.
